Subtitler — Run in Firefox (macOS / Windows / Linux)
=====================================================

You CANNOT just double-click index.html. Firefox blocks the things this app
needs (Web Workers, ES modules, fetch) when a page is opened directly via
file://. The page will appear blank.


STEP-BY-STEP — macOS / Linux
----------------------------

1. Open Terminal.

2. Paste:

       cd ~/Downloads/Subtitler && python3 -m http.server 8765

   - LEAVE THIS WINDOW OPEN.

3. In Firefox:

       http://localhost:8765/index.html


STEP-BY-STEP — Windows
----------------------

1. Win+R → "cmd".

2. Paste:

       cd %USERPROFILE%\Downloads\Subtitler
       python -m http.server 8765

3. In Firefox:

       http://localhost:8765/index.html


FIREFOX-SPECIFIC TIPS
---------------------

- Hard refresh: Cmd+Shift+R (macOS), Ctrl+Shift+R (Windows/Linux).

- Firefox's per-tab memory limit is ~3 GB — between Safari (~2 GB) and
  Chrome (~4 GB). For long files on Small, prefer Chrome.

- Firefox's strict tracking protection doesn't affect the local version.


REQUIREMENTS
------------

- Python 3.
